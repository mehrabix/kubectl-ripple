ripple

See the ripple before you make the change. This URL is a Helm chart repository.

Add the repository

helm repo add ripple https://mehrabix.github.io/kubectl-ripple
helm repo update

Install

helm install ripple-scan ripple/ripple \
  --namespace ripple-system --create-namespace

Or install over OCI

helm install ripple-scan oci://ghcr.io/mehrabix/charts/ripple \
  --namespace ripple-system --create-namespace
